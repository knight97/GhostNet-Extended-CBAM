# GhostNet-Extended-CBAM

The following project extends the work of GhostNet using an Attention Module called Convolutional Bloack Attention Module (CBAM): 

The goal of the project is to implement CBAM as an attention module into the GhostNet architecture. This will add spatial attention to the model potentially increasing the inferencial information of the feature maps generated by the model on a dataset. 

The original publication of GhostNet can be found at: 
GhostNet: More Features from Cheap Operations. CVPR 2020. [arXiv] [Most Influential CVPR 2020 Papers]
By Kai Han, Yunhe Wang, Qi Tian, Jianyuan Guo, Chunjing Xu, Chang Xu.

The following github repository contains the following folders: 

ProjectCode: Files containing the Colab scripts used in the training and testing of models

Models: All models created within the project

StateDirectory: State directory paths used in the training progress. 

Video: Video explaining project and outcome/conclusions

# Environment Set-up:

The requirements for the scripts are loaded within the .py files at the beginning of each .pynb file. No further requirements should be needed beyond downloading the add-ons if required. If you have a Python package not installed use: !pip install NAME_OF_PACKAGE. Furthermore, a requirements.txt file has been included if prefered. 

# Use-Instructions: 

Implementation:

This folder provides the PyTorch code with pretrained models of GhostNet and the extended GhostNet-CBAM on ImageNet and CIFAR-10.

*Run the Testing_CIFAR10.ipynb file to reproduce the results of the extention model on CIFAR-10 and the linear transformationaw trade-off analysis

*Run the Testing_ImageNet.ipynb file to reproduce the results of the extension model on ImageNet.

*Run FileConverter_CommandLines.ipynb if you need assistance converting files from .pynb files to .py, prefer to download the subset of ImageNet used in this experiment, or would like to verify your directories are in order. 


# Requirements:

The code was verified on Python 3.11.12, PyTorch version: 2.6.0+cu124.
