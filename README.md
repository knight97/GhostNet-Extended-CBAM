# GhostNet-Extended-CBAM

The following project extends the work of GhostNet using an Attention Module called CBAM: 

The goal of the project is to implement CBAM as an attention module into the GhostNet architecture. This will add spatial attention to the model potentially increasing the inferencial information of the feature maps generated by the model on a dataset. 

The original publication of GhostNet can be found at: 
GhostNet: More Features from Cheap Operations. CVPR 2020. [arXiv] [Most Influential CVPR 2020 Papers]
By Kai Han, Yunhe Wang, Qi Tian, Jianyuan Guo, Chunjing Xu, Chang Xu.

The following github repository contains the following folders: 

Testing Files: Files containing the Colab scripts used in the training and testing of models

Models: All models used within the project

State_Directory: State directory paths used in the training progress. 

Video: Video explaining project and outcome/conclusions

Datasets: Datasets of ImageNet and CIFAR-10 used in the model training

# Environment Set-up:

The requirements for the scripts are loaded within the .py files at the beginning of each .pynb file. No further requirements should be needed beyond downloading the add-ons if required. If you have a Python package not installed use: !pip install NAME_OF_PACKAGE.

# Use-Instructions: 

Implementation:

This folder provides the PyTorch code with pretrained models of GhostNet and the extended GhostNet-CBAM on ImageNet and CIFAR-10.

*Run the Testing_CIFAR10.ipynb file to reproduce the results of extention model on CIFAR-10 and the trade-off analysis

*Run the Testing_ImageNet.ipynb file to reproduce the results of the extension model on ImageNet.

*Run FileConverter_CommandLines.ipynb if you need further set up assistance or help converting .pynb files to .py


# Requirements:

The code was verified on Python 3.11.12, PyTorch version: 2.6.0+cu124.
